# homebrew-evnx

Homebrew tap for [evnx](https://github.com/urwithajit9/evnx) — a CLI tool for
managing `.env` files.

## Install
```bash
brew install urwithajit9/evnx/evnx
```

Or tap first then install:
```bash
brew tap urwithajit9/evnx
brew install evnx
```

## Documentation

Full documentation at [evnx.dev](https://www.evnx.dev).
